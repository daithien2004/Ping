# Trạng thái Ping v0.2.0

[ADR-0059](../adr/0059-defer-paid-infrastructure.md). Thứ tự thi công: Pha 3 → Pha 4 → Pha G →
Pha 5 (dev, Qdrant local, embedding cục bộ) → Pha 6 (phần không cần staging) → Pha 2 → Pha 6
(load/chaos) → Pha 7. Cổng nghiệm thu §12 giữ nguyên, chỉ dời các mục cần staging.
